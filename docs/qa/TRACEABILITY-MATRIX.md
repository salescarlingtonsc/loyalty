## Per-change expansion template

Copy this below the working matrix or into a phase evidence document before
implementation:

| Field | Required entry |
| --- | --- |
| Requirement ID | Existing ledger ID or a new stable ID |
| Source | Owner message date, screenshot description, audit item, or defect |
| Exact acceptance | Observable UI plus persistent data result |
| Owner configuration | Toggle, catalogue, branch, programme, permission |
| Staff operation | Role, action, confirmation, correction |
| Customer projection | UI/history/balance/notification result |
| Data contract | Tables/RPCs/events and idempotency key |
| Fixture | Named fixture and concrete values |
| Negative states | Disabled/empty/denied/retry/refresh/mobile/branch as applicable |
| Regression | Exact test file and test name |
| Browser evidence | Artifact path, viewport, role, candidate hash |
| Database evidence | Environment, query/test artifact, before/after values |
| Reviewer | Independent reviewer and verdict |
| State | One ledger lifecycle state |
