## Expansion rationale

The initial file set established that customer behavior is concentrated in `app/index.html`, with standalone join, service worker and Capacitor configuration as separate trust boundaries. Further inspection is limited to the exact renderers, RPC migrations and existing tests named by a finding; repository-wide refactoring is out of scope.
